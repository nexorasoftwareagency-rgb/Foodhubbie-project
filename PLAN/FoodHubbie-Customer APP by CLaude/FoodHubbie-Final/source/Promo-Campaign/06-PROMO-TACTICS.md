# Promo tactics — every feature framed as owner revenue outcome

Format: Problem → Feature (file) → Demo beat → Outcome.

## 1. QR table ordering
Problem: flagging waiters, slow turns, "where is my food".
Feature: token QR → welcome → split/share groups → customize → Pending→Placed → live
status → help/water/bill taps → Promos tab reviews (02-FLOW-qr-dinein.md).
Demo: scan → START ORDERING → add combo → PLACE ORDER → status bar → Request Water → Request Bill.
Outcome: ~20–35% faster turnover, fewer floor trips, second orders mid-meal, Google stars per table.

## 2. WhatsApp ordering + coupons
Problem: 25–30% aggregator commission, messy phone orders.
Feature: Menu/Order intent → webview link → coupon server-validated → S1–S9 invoice updates
(03-FLOW-whatsapp-ordering.md). Discount reports per code (04).
Demo: text `menu` → tap link → apply DIWALI7X → order → invoice updates arrive.
Outcome: direct orders keep full margin; codes drive trial without leakage.

## 3. Festive broadcast campaigns
Problem: dead days, dormant customers.
Feature: 25 templates → consent audience → test-to-self → paced launch → monitor/stop (04).
Demo: Diwali template → 300 recipients → preview → test message on own phone → launch → progress bar.
Outcome: 10–15% dormant return, repeat visits in days not months; ban-safe by construction.

## 4. Combos raise the average ticket
Problem: low per-customer bill.
Feature: combo builder → POS tiles → one-tap bundle (04-C).
Demo: build "Family Feast" (2 pizza + garlic bread + coke, ₹ off) → POS tile → add → bill jumps.
Outcome: +12–30% ticket size with zero staff scripting.

## 5. Discounts that fill off-peak
Problem: empty lunch hours.
Feature: Category + schedule (Mon–Fri 12–3) + per-customer/global caps + exclusive groups (04-B).
Demo: "Lunch Special 10% Pizzas" → Reports 234 redemptions ₹12,600 → CSV export.
Outcome: off-peak covers without stacking leakage.

## 6. Reviews on autopilot
Problem: invisible on Google, no social proof.
Feature: Promos-tab links (Google/Instagram/Facebook/WhatsApp) + post-meal feedback ping
+ 1★ respond-via-WhatsApp (02-§7, 01-§18).
Demo: Promos tab → Rate us on Google → Feedback filter 1★ → respond.
Outcome: 3–5× more reviews; negatives fixed before they go public.

## 7. Riders that protect the rating
Problem: late cold food, COD chaos.
Feature: proximity-gated accept → slide+GPS trip → OTP handover → cash/UPI sheet →
Live Tracking + Rider Insights (05, 01-§17/§19).
Demo: accept → slides → OTP → payment → map follow → earnings sort.
Outcome: on-time % up, refunds down, proof in every dispute.

## 8. Costs under the same roof
Problem: profit leaks to fees, waste, over-discounting.
Feature: Payments reconciliation + Expenses approvals + Costs channel audit + Security Audit
+ staff ceilings (01-§21/22/23/24).
Demo: Payments filter → Expenses over-budget red → Costs channel compare → Audit Fix.
Outcome: every rupee in and out reconciled — true profit, not vibes.

## 9. Win-back + reorder loops (creative layer, research-backed)
Saved-favorites one-tap reorder, dormant 30/60/90-day + birthday coupon broadcasts,
reservation confirm + 2h reminder (40–55% fewer no-shows), dessert prompt after mains
(15–20% accept), shift aggregator buyers to direct with 10% direct discount.
Outcome: 30–50% repeat-order lift, recovered peak covers, +€2–4 per order.
