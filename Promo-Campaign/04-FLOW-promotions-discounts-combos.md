# Promotions + discounts + combos tour — real clicks, with explanations

## A. Campaign (Promotions tab)
**Clicks:** Write (≤1500 chars, tokens {name} {phone} {lastOrderDate} {storeName} {couponCode},
greeting prefix, image, menu footer + menu image, STOP footer checkbox) → audience:
All-consenting / Active-30d / upload CSV-XLS (phone-column auto-detect, deduped, STOP
subtracted, 300 cap badge) → Preview (sample Aarav/9876543210) → Send test to me
(≤10s sent/failed toast) → money gate (need = recipients × ₹1/token; shortfall blocks,
Supreme grants tokens) → Launch now or Schedule + quiet hours → Active pane live
progress (currentIndex/recipients, sent/failed, heartbeat) → per-campaign Stop or
EMERGENCY STOP ALL. 25 templates in 7 categories (New-Customer, Discounts incl. BOGO,
Weekend/Seasonal, Win-back, Referral/Loyalty, Launches, Birthday).
**Say:** "Festive offer to 300 customers before lunch — tested on your own phone first, paced
8–15 seconds apart, stoppable mid-flight."

## B. Discounts + coupons
**Clicks:** Discounts → New Discount → 4-step wizard (1 basics: name, type Global/Category/
New-Customer/Coupon, %/₹, category chips, coupon code; 2 window + channel WhatsApp/POS/Both/
Web/All; 3 limits: min-subtotal, exclusive-group, per-customer/global caps, stackable;
4 review) → Save → toggle on → Reports → View Code Uses (who/when/saved) → Export CSV.
Generate: prefix DIWALI → word-codes, Stackable toggle. Report KPIs: redemptions,
total savings ₹, active count, avg/redemption + channel split + last-50 list. Same engine
evaluates in POS, Tables, QR (food-subtotal base, best-per-group, no stacking leaks).
**Say:** "Diwali codes that can't be abused — and a report proving each code's rupees vs orders lifted."

## C. Combos (POS tiles)
**Clicks:** Combos → Add Combo → pick dishes + qty + percentage/fixed + dates + image →
Save → tiles atop POS grid (active-window enforced) → one tap explodes to discounted lines.
**Say:** "Bundle the slow mover with the star — one tap, bigger ticket, every rush hour."

300 recipients/campaign · 300/day · 8–15s random + 60–120s pause per 30 · warmup
20→250 over 7 days · circuit-breaker at >35% fails · kill-switch + master toggle ·
STOP honored at compose AND send · promos hard-blocked on non-Meta transport.
