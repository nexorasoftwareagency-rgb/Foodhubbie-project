·Model — measured facts & labeled assumptions

Measured (live DB, P3-8/P3-9)

  • Menu payload: ~75 KB/scan — images in Firebase Storage (default), never base64 in RTDB (base64-in-RTDB = 730 KB/scan, +₹259–22,786/mo)
  • Order record 687 B · menu shell 388 KB · admin 0.5 + riders 1.8 GB/mo/rest
  • Bot worker 110–155 MB/outlet · t3.small caps ~10 outlets
  • Order-flow messages (bot/index.js), delivery orders only (dine-in = QR table → POS): greeting + menu CTA + placed + confirmed + ready + OFD/OTP + reached + delivered → 8 msgs/order · 1 conversation/order
  • EC2 runs only the WhatsApp stack → no bot = server ₹0

Assumptions (change via flags)

  • scans/day = 1.5 × orders (P3-8 calibration)
  • bot msgs = 4 × orders/day · promos = 0.1 × orders/day (--mktg=)
  • No free service allowance in the model — every message billed ₹0.115; promos at ₹0.86/msg × 0.1 promo msgs per order/day (the "0.1" is frequency, not rupees)
  • ₹88/$ · server: 10 rest→t3.small ₹1,338 · 50→t3.large ₹5,342 · 100→t3.xlarge ₹10,692
  • Image mode: --fixed = images in Firebase Storage

·Blaze upgrade via UPI — the ₹1,000 question

Why ₹1,000 first
India + INR billing requires a one-time prepayment (₹500–1,000) before UPI can be registered — it's prepaid balance, not a fee, refunded if unused. Pay at console.cloud.google.com/billing → Payment overview → “Prepayment pending” → Pay now → payment method UPI → QR → scan with GPay/PhonePe/Paytm/BHIM. Then Firebase → Upgrade → Blaze links that account. Blaze subscription = ₹0; free allowances kept; budget alerts don't cap usage (set ₹850/₹4,250/₹8,500).

Full guide: BLAZE-UPGRADE-UPI-GUIDE.md · Storage enablement: FIREBASE-STORAGE-USAGE.md

·Cost levers (ranked)

  1. Images in Firebase Storage (default) — never base64 in RTDB; storing them there would add ₹259–22,786/mo and 10× the scan payload.
  2. Prune logs/ — 67% of nodes; protects the free 1 GB storage (₹440/GB-mo = steepest rate).
  3. Budget alerts ₹850/₹4,250/₹8,500 + .validate rate rules on anonymous sessions.
  4. App Check on menu — stops leaked-URL scanners burning paid bandwidth.
  5. Bot strategy ladder: Meta billed (4) → cut promos --mktg=0 → Baileys (2) → no bot (1).
  6. EC2 1-yr commitment ~37% off server; cheaper host: Vultr/DO ₹880–1,056 (see below).
